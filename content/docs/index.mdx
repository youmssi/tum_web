Tûm is a project execution workspace. It keeps tasks, schedules and team activity in one place so that everyone can see what is planned, what is late and who is working on what.

## What you can do with Tûm

- Plan a project as a list, a board, a calendar or a Gantt timeline. All views show the same tasks.
- Link tasks with dependencies and let the schedule follow when a date moves.
- Follow progress with milestones, workload and analytics.
- Work together with comments, mentions, watchers and email notifications.
- Export a timeline as an image, a PDF or a vector file, and a whole project to Excel.
