## Project views

Each project offers several views of the same tasks. A change made in one view appears in all the others.

| View      | Use it to                                                                                    |
| --------- | -------------------------------------------------------------------------------------------- |
| Overview  | See the project summary, progress and upcoming dates.                                        |
| List      | Sort, filter and edit tasks in bulk.                                                         |
| Board     | Move tasks between statuses by drag and drop.                                                |
| Calendar  | See tasks by due date.                                                                       |
| Timeline  | Schedule tasks on a Gantt chart with dependencies. See [Timeline and Gantt](/docs/timeline). |
| Workload  | Check who is overloaded across the period. Pro plan.                                         |
| Analytics | Follow completion trends and status breakdowns. Pro plan.                                    |
| Activity  | Read the history of changes in the project.                                                  |

## Task fields

- **Title and description** explain the work.
- **Status** follows the project's workflow. You can rename and reorder statuses in the project settings.
- **Assignee** is the person responsible. They are notified when a task is assigned to them.
- **Priority** and **labels** help you sort and filter.
- **Start date** and **due date** place the task on the timeline and the calendar.
- **Progress** is a percentage from 0 to 100.
- **Milestone** marks a key date. Milestones show as diamonds on the timeline.

## Filters and saved filters

In the list view, filter by status or priority. Save a combination of filters to reuse it later.

## Comments, mentions and watchers

Comment on a task to discuss it. Type `@` followed by a name to mention a teammate; they receive a notification. Watch a task to be notified when its status or assignee changes.

## Notifications

Open **Notifications** and then **Preferences** to choose which emails you receive, for example when a task is assigned to you or when someone comments on your task. Links in these emails open the task directly.

## Archiving

Archive a project when the work is finished. Archived projects stay readable and can be restored. On the Free plan, only active projects count towards the limit of three.
