## Les vues d'un projet

Chaque projet propose plusieurs vues des mêmes tâches. Une modification faite dans une vue apparaît dans toutes les autres.

| Vue            | Pour                                                                                                              |
| -------------- | ----------------------------------------------------------------------------------------------------------------- |
| Vue d'ensemble | Voir le résumé du projet, l'avancement et les prochaines dates.                                                   |
| Liste          | Trier, filtrer et modifier les tâches en masse.                                                                   |
| Tableau        | Déplacer les tâches entre les statuts par glisser-déposer.                                                        |
| Calendrier     | Voir les tâches par échéance.                                                                                     |
| Planning       | Planifier les tâches sur un diagramme de Gantt avec des dépendances. Voir [Planning et Gantt](/fr/docs/timeline). |
| Charge         | Repérer les personnes surchargées sur la période. Offre Pro.                                                      |
| Analyses       | Suivre l'évolution des tâches terminées et la répartition par statut. Offre Pro.                                  |
| Activité       | Consulter l'historique des modifications du projet.                                                               |

## Les champs d'une tâche

- **Titre et description** expliquent le travail.
- **Statut** suit le flux de travail du projet. Vous pouvez renommer et réordonner les statuts dans les paramètres du projet.
- **Responsable** désigne la personne en charge. Elle est notifiée lorsqu'une tâche lui est assignée.
- **Priorité** et **étiquettes** servent à trier et filtrer.
- **Date de début** et **échéance** placent la tâche sur le planning et le calendrier.
- **Avancement** est un pourcentage de 0 à 100.
- **Jalon** marque une date clé. Les jalons s'affichent sous forme de losange sur le planning.

## Filtres et filtres enregistrés

Dans la vue liste, filtrez par statut ou par priorité. Enregistrez une combinaison de filtres pour la réutiliser.

## Commentaires, mentions et abonnements

Commentez une tâche pour en discuter. Tapez `@` suivi d'un nom pour mentionner un collègue ; il reçoit une notification. Abonnez-vous à une tâche pour être prévenu quand son statut ou son responsable change.

## Notifications

Ouvrez **Notifications** puis **Préférences** pour choisir les e-mails que vous recevez, par exemple lorsqu'une tâche vous est assignée ou qu'un commentaire est ajouté à votre tâche. Les liens de ces e-mails ouvrent directement la tâche.

## Archivage

Archivez un projet lorsque le travail est terminé. Les projets archivés restent consultables et peuvent être restaurés. Avec l'offre Free, seuls les projets actifs comptent dans la limite de trois.
