## Components

| Component             | Image                            | Role                                                |
| --------------------- | -------------------------------- | --------------------------------------------------- |
| Web                   | `ghcr.io/youmssi/tum_web`        | Next.js interface and authentication                |
| App                   | `ghcr.io/youmssi/tum_app`        | REST API, real-time updates, emails, scheduled jobs |
| PostgreSQL 17         | Any managed or self-run instance | Shared database                                     |
| S3-compatible storage | MinIO, Cloudflare R2, AWS S3     | Attachments and avatars                             |
| Email                 | SMTP relay, Resend or Brevo      | Notifications and invitations                       |

## Quick start

The [infrastructure repository](https://github.com/youmssi/tum_infra) contains a Docker Compose file for PostgreSQL, MinIO and a local mail catcher.

```bash
git clone https://github.com/youmssi/tum_infra.git
cd tum_infra
cp .env.example .env
docker compose up -d
```

Then start the app and web containers with the variables below.

## Required configuration

### Web

| Variable                      | Description                                                       |
| ----------------------------- | ----------------------------------------------------------------- |
| `BETTER_AUTH_URL`             | Public URL of the web app, for example `https://tum.example.com`. |
| `NEXT_PUBLIC_BETTER_AUTH_URL` | Same value as `BETTER_AUTH_URL`.                                  |
| `BETTER_AUTH_SECRET`          | Long random secret. Generate one with `openssl rand -base64 32`.  |
| `DATABASE_URL`                | PostgreSQL connection string.                                     |
| `NEXT_PUBLIC_API_BASE_URL`    | Public URL of the app (API).                                      |
| `INTERNAL_API_URL`            | URL the web uses to reach the app on your private network.        |
| `INTERNAL_SERVICE_TOKEN`      | Shared secret between web and app. Use the same value on both.    |

### App

| Variable                                                                 | Description                                                                                              |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`, `DATABASE_USERNAME`, `DATABASE_PASSWORD`                 | PostgreSQL connection.                                                                                   |
| `AUTH_JWKS_URI`                                                          | `https://<web>/api/auth/jwks`, used to verify sign-in tokens.                                            |
| `CORS_ALLOWED_ORIGINS`                                                   | Public URL of the web app.                                                                               |
| `WEB_URL`                                                                | Public URL of the web app: email links, payment return page and internal calls.                          |
| `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET` | Object storage.                                                                                          |
| `MAIL_TRANSPORT`, `MAIL_FROM`                                            | `smtp`, `resend` or `brevo`, or several in order of preference (`resend,brevo`); and the sender address. |
| `INTERNAL_SERVICE_TOKEN`                                                 | Same value as on the web.                                                                                |

Leave `TUM_CLOUD_ENABLED` unset or `false`. This turns off plan limits and payments, so every workspace gets every feature.

## Updating

Pull the new images and restart the containers. Database migrations run automatically when the app starts. Back up your database before each update.
